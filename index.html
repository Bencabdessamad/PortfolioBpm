Flagship freelance project

Port Management Information System

An operations system for a port: who arrives, which resources they need, and what traffic to expect next. It combines an offline-first mobile app with Python decision-support services.

Problem
Port operations run on vessel calls, resources and services that must be planned together, often where connectivity is unreliable, and planners need to anticipate traffic rather than react to it.
My role
Functional analysis, architecture and full-stack development across four modules: users, vessel calls, resources and port services.
Approach
An offline-first React Native app with local SQLite storage and synchronisation, REST APIs, KPI dashboards and reports.
Applied AI
A Python rule-based engine that proposes resource allocation, and a traffic forecast built from historical vessel visits, with confidence intervals so planners see the uncertainty.
  • React Native
  • Python
  • REST APIs
  • SQLite
  • Firebase
  • Offline sync
  • Dashboards & KPIs
